## 3. WHAT THIS FILE CANNOT DERIVE, and no file over `/data` can

L-0219's other partition — **139 citations returning no document, split 54 refused / 50 under 500 characters of text / 23 without a DNS record / 12 forbidden** — rests on requesting each root through an explicit resolver and measuring the response as text rather than bytes. **That is a retrieval result. No retrieval is stored in this repository**, so the number cannot be recomputed here and is not printed here.

`tools/source-response-check.mjs` measures the same property live and reports it with the artefacts of its own run named. **It is a different object from a derivation: it tells a reader what the hosts do TODAY, not what they did when the record was written.**

The same boundary applies to **L-0218**, whose three unreadable channels are a retrieval finding throughout.
