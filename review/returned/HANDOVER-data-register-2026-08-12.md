# HANDOVER — the internal register in `/data` prose

**For a research session picking this up cold. Nothing here has been changed.**

## WHY A CODE SESSION DID NOT DO IT

`/data` prose is research-owned. The narrow source-edit amendment lets a run apply only a correction
**that run itself raised and evidenced**; this one arrived from an external review. So the class is
measured and handed over, not edited.

**A render-time move was tested and rejected**, which forecloses the obvious shortcut: of the dated
stamps in `assessmentNote`, **16 lead their field and 12 sit mid-sentence inside the argument.** A
leading-stamp rule would work on 16 and mangle 12, and a parser over authored prose is the
hand-rolled-normaliser class the corpus already forbids. **The trail can be moved. Only a session
that can read the prose can move it.**

## WHAT THE REVIEWER OBJECTED TO, EXACTLY

Three examples, and the distinction between them matters:

> "T4 BY THE SCHEMA'S LETTER" — reads as the author arguing with the site's own classification.
> "VALUE-AND-NOTE RECONCILED 2026-08-03" — repository archaeology inside "Why this verdict".
> "A low figure is not a fault…" — lectures an imagined reader.

The third was in code and **is fixed**. The first two are `/data`.

## THE CLASS, MEASURED

Across `caveat`, `assessmentNote`, `notes`, `whatHappened` and `summary`:

| pattern | occurrences |
|---|---|
| dated rescore / reconcile stamp (`RESCORED`, `RE-FILED`, `RECONCILED`, `TIER CORRECTED`, `BOUNDED` + a date) | **40** |
| repository archaeology (*commit*, *batch*, *phase n*, *this run*, *drop*, *authoring pass*) | **65** |
| tier letter asserted in prose | **38** |
| schema or field name in prose | **21** |

Counts are **candidates, not defects** — the corpus's own rule. Each must be read before it is banked.

## THE RULE SUCH A SESSION MUST ESTABLISH

**Three questions, and the second is the one that does the work.**

**1. Is this marker provenance a reader needs, or repository history?** A reader needs to know that a
figure was superseded and by what. A reader does not need the commit that did it, the batch that
raised it, or the date the note was reconciled with its value.

**2. Does rule 3 require it to stay VISIBLE, or only to stay RECORDED?** This is the distinction the
brief draws and it is not obvious. **A correction's withdrawn wording stays visible** — that is rule
3 and it is not what is being objected to; a reader meeting a corrected figure is entitled to see
what it replaced. **A dated reconciliation stamp is a different object**: it records *when the
repository noticed*, not *what the record now says*. The first belongs in the argument; the second
belongs in `docs/verification-log.md`, which already exists for exactly this and is append-only.

**The operational test:** delete the marker and ask whether a reader loses a fact about **India or
its statistics**, or only a fact about **this repository's editing history**. If the first, it stays
in the prose. If the second, it moves to the log, and the record keeps the substantive sentence the
stamp was attached to.

**3. Where the marker is mid-sentence, is the sentence still true without it?** Twelve are. Those
cannot be cut mechanically; each needs the sentence re-read.

## WHAT MUST NOT CHANGE

- **The absence vocabulary stays, including its emphasis.** *"DISCONTINUED, NOT MERELY UNRETRIEVED"*
  is rule 4a working — an absence rendered unlike a finding. **The reviewer misattributed it**, and a
  session sweeping for shouty capitals will delete the rule along with the register.
- **Withdrawn wording stays quoted**, per rule 3 and the correction convention.
- **No `points[]` value and no `assessment` may move.** That is a shipped verdict and a stop.

## WHERE TO START

The 40 dated stamps, because they are the most mechanical and the test above separates them
cleanly. The 65 archaeology passages are the largest group and the least uniform. The 38 tier letters
are probably the least urgent: a tier letter beside a citation is provenance a reader can use, and
the objection was to tier letters **argued with** rather than stated.
